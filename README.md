# Digital-advertising-analytics-dashboard
Self-directed advertising analytics project analyzing campaign performance, budget efficiency, and client-facing KPIs using Python, pandas, Excel, and Tableau-ready data.

This project was built to demonstrate how campaign-level data can be transformed into clear performance insights, executive reporting, and actionable business recommendations.

Project Overview

The analysis evaluates 750+ synthetic campaign-market observations across multiple advertising campaigns and markets.

The project focuses on:

Campaign performance analysis

Budget pacing and efficiency

KPI monitoring

Client-facing reporting

Performance optimization

Business insight generation

Business Questions

This project was designed to answer questions such as:

Which campaigns generate the strongest return on ad spend?

Which campaigns are underperforming relative to budget?

Where should advertising spend be increased or reduced?

Which markets deliver the strongest campaign efficiency?

How are campaign KPIs changing over time?

Which performance trends should be highlighted to clients or leadership?

Project Workflow

1. Data Preparation

Campaign-level data was cleaned and structured using Python and pandas.

The workflow included:

Data validation

KPI calculations

Campaign aggregation

Market-level analysis

Weekly trend analysis

Budget-performance comparisons

2. Performance Analysis

Campaign performance was evaluated across efficiency, engagement, conversion, and financial metrics.

The analysis focused on identifying:

High-ROAS campaigns

Inefficient spend

CPA outliers

Budget pacing issues

Strong and weak markets

Opportunities for budget reallocation

3. Dashboard & Executive Reporting

The results were translated into a business-facing dashboard and executive work sample designed to make campaign performance easy to understand.

The reporting layer includes:

Campaign KPI summaries

ROAS comparisons

Spend and budget analysis

Performance trends

Client-facing recommendations

Dashboard Preview

Key Takeaway

The project demonstrates how advertising data can be translated from raw campaign metrics into structured reporting and actionable business insights.

The objective was not only to calculate performance metrics, but to communicate the results in a way that could support client conversations, business reviews, budget decisions, and campaign optimization.
